# Cooploy Web — Site static

Site static de prezentare pentru Cooploy — studio AI, Web & SEO din Almere, Olanda.

![Screenshot](screenshot.png)

## Despre

Site simplu HTML/CSS care prezintă serviciile Cooploy: automatizare cu AI, dezvoltare web și optimizare SEO pentru clienți din Olanda și Europa.

## Tech Stack

- HTML5, CSS3
- JavaScript Vanilla
- PWA (manifest + service worker)

## Structură

- `index.html` — pagina principală
- `nl.html` — versiune în olandeză
- `mobile.css` — stiluri pentru mobil
